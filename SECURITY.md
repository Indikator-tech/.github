# Security Policy

## Reporting a vulnerability
Email **help.indikator@gmail.com** with details and reproduction steps. Please do not open a public issue. We aim to acknowledge within a few business days.

## Scope & expectations
- These are educational tools provided under MIT with no warranty.
- Never include real credentials, keys, or account data in reports, issues, or PRs.
- If you find secrets accidentally committed anywhere in our repos, report privately so we can rotate and purge history.

## For users
- Keep your own API keys in environment variables or a secrets manager — never in code.
- Review and test any example against a sandbox/demo account before using real capital.
