# Contributing to Indikator open-source

Thanks for your interest! These repos are small, practical tools for trading developers.

## Ground rules
- **No secrets.** Never commit API keys, tokens, account numbers, or real credentials. PRs that do will be closed.
- **No trading advice.** Code and docs stay educational/technical — no "signals," no return claims.
- **Safe examples only.** Use sandbox/demo endpoints and placeholders (`<API_KEY>`, `<ACCESS_TOKEN>`).

## How to contribute
1. Open an issue describing the change (bug/feature) before large PRs.
2. Fork → branch (`feature/short-name`) → commit with clear messages.
3. Keep PRs focused and small. Add/update examples and docs.
4. Match the existing style. Add tests where it makes sense.
5. One reviewer approval required; CI must pass.

## Code style
- Python: PEP 8, type hints where helpful, docstrings on public functions.
- MQL: clear names, comments on non-obvious logic, no magic numbers.

## Reporting security issues
See `SECURITY.md` — please do **not** open public issues for vulnerabilities.
